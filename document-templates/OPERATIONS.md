# document-templates operations

Generated from `definition.mjs` by `npm run sync` — do not edit by hand.

Each operation is a node `document-templates.<operation>` (outputs `data`, `next_cursor`) and a tool `<operation>`.
**Bold** parameters are required.

| Operation | Description | Parameters |
|-----------|-------------|------------|
| `list_templates` | Lists the ready-made templates and the kinds of template you can bring yourself (your own layout, a PDF form, a Word document), with the operation for each | language |
| `describe_template` | Shows what a template needs before you fill it: for the invoice or your own layout, its fields with an example; for a Word document, its {{placeholders}}; for a PDF form, its boxes (or that it has none) | template, password, include_layout, language |
| `save_template_copy` | Saves your own copy of a ready-made template in your documents folder (in the folder Templates), so that you can change its layout while the original stays as it is (for a logo, a colour, the title, the language or hidden columns no copy is needed: see save_brand). Nothing is ever replaced: when the name is taken, the copy gets a number. To use your copy, give its `path` as `template` when creating a PDF | template, name, language |
| `next_number` | Gives the next number of a series, such as INV-2026-0001, then INV-2026-0002, so that no two documents get the same number. The count starts again with each new year (or month, when the pattern has one). The last number is remembered in your documents folder | pattern, date, start_at, preview, language |
| `save_brand` | Saves how your documents look and your own details, once, so that every later document uses them: a logo, an accent colour, the document's title, the language, other label texts, which optional parts show, your business name and address, your payment details and standard notes. Give only what should change; everything saved before stays. Nothing has to be edited in a template | look, seller, payment_details, notes, name, reset |
| `show_brand` | Shows what is saved for your documents: the logo, accent colour, title, language, label texts, hidden parts, your own details, payment details and notes. Also lists the colour names an accent colour may use | name, language |
| `check_values` | Checks everything render_pdf would check, without saving anything or using up a number: the values, amounts, currency and dates, the fields the template needs, the logo and the file name. The PDF is drawn to be sure, then thrown away. The result says `ok` and, when something is wrong, the `problem` in plain words; when it is fine, the totals, the number the document would get with `number_pattern` and where it would be saved. The problem is written in the document's language (English or Indonesian). Use it before asking for an approval and taking a number | template, values, values_file, calculate, look, brand, background, number_pattern, number_start_at, folder, file_name, if_exists |
| `render_pdf` | Creates a PDF document, such as an invoice, from a template and your values: the ready-made `invoice`, or your own template. Totals are calculated for you and a long list of items continues on the next page. `look` gives it your logo, colour, title and language and hides parts you do not use; what save_brand saved is used by itself. With `number_pattern` it takes the next number of a series itself, and only once the PDF is saved, so a failed document leaves no gap. The PDF is saved in your documents folder, sorted by year and month (2026/11/INV-2026-0001.pdf), and a document that is already there is never replaced. The result says where the file is | template, values, values_file, calculate, look, brand, background, number_pattern, number_start_at, folder, file_name, if_exists |
| `fill_pdf_form` | Fills in a PDF form (a PDF with boxes you can type in) and saves the result as a new PDF in your documents folder. A protected form, as many official forms are, is filled in too, and the result is saved without the protection. `fields` says which value goes into which box; a value may use {{placeholders}} from `values`, including calculated totals such as {{totals.total \| money}}, and your details saved with save_brand ({{business.name}}, {{payment.bank}}). A PDF without such boxes (a scan, a picture, plain pages) cannot be filled in: use render_pdf | **template**, fields, fields_file, values, values_file, calculate, brand, password, flatten, folder, file_name, if_exists |
| `fill_docx` | Fills in a Word document that has {{placeholders}} (.docx, or a Word template .dotx) and saves the result as a new Word file in your documents folder. A table row between {{#items}} and {{/items}} repeats for every item, totals are calculated for you, and your details saved with save_brand fill {{business.name}}, {{business.address \| join}}, {{payment.bank}} and the like. The result is a Word file, not a PDF | **template**, values, values_file, calculate, brand, folder, file_name, if_exists |
