# Upwork Agent Plugin skills (upstream copy)

Unmodified copies of the four Agent Skills of the Upwork Agent Plugin,
<https://github.com/upwork/upwork-agent-plugin>, commit
`7908a7e68f4a3c462b4eb5bc884ee69c82ecff59` (2026-10-28), Copyright Upwork Inc.,
licensed under the Apache License, Version 2.0 (`LICENSE` in this folder).
The upstream repository has no NOTICE file.

graphrt does not load these files (it has no Agent Skills runtime).
`../guide.md` is a condensed, modified version of them that the graphrt
desktop app puts into the agent builder's prompt while this plugin is
installed. When the upstream skills change, update these copies and port the
changes to `../guide.md`.
